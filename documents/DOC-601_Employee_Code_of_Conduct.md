## Purpose
This document establishes the mandatory code of ethical conduct, data handling rules, and confidentiality standards for all employees.

## Core Rules
- Employees must respect information access boundaries. Never attempt to query or bypass Row-Level Security barriers on enterprise databases.
- Passwords and security tokens must never be shared across teams.
- Standard office work hours are 9:00 AM to 6:00 PM with flexible remote policy.
- Annual leave entitlement is 24 paid vacation days plus 12 national holidays.
